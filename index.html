02 — Duties

Three things it is for.

  1. 01

    Build

    Real files, real commands, and a browser when the work needs the web. The result is something you can open, not a transcript that vanishes when the chat does.

  2. 02

    Host

    A web app it produces is meant to live at its own link — on your machine, or in Onyra Cloud, which stays up when the lid is closed.

  3. 03

    Pay

    APIs and compute are billed per use. The agent pays from a wallet you fund and cap. Each payment is designed to leave a receipt you can read on-chain.

05 — Capabilities

What the desk can reach for.

These are the tools Onyra is being built around. The order they arrive is on the roadmap. None of them can be installed today.

  • 01

    Files and commands

    It edits real files and runs real commands, on a machine you can inspect.

  • 02

    A browser

    When the task needs the web, it opens one: to read, to check, to confirm the page it just hosted.

  • 03

    Memory on disk

    Plans and preferences are files. You can open the folder. Nothing important lives only in a session.

  • 04

    Auto mode, judged

    Auto mode can continue without a prompt on every step. A safety judge reads the plan before it spends, deletes, or publishes.

  • 05

    Helpers

    It can hand a slice of work to another agent, then gather what comes back. You still see one brief and one result.

  • 06

    Chat, MCP, skills

    Telegram, Discord, and Slack. MCP servers, plugins, and skills — the same agent, more doors.

06 — Two rooms

A cloud that stays awake. A wallet with a ceiling.

Cloud

It keeps the desk when you close the lid.

Local work pauses when the computer sleeps. Onyra Cloud is the other room: tasks continue, services stay up, and every web app the agent ships is meant to get a live link of its own.

The cloud desk

Wallet

It pays for what it uses.

APIs and compute are per use. The agent pays from its own wallet, inside a ceiling and an approval rule you set. A payment can leave an on-chain receipt. The wallet is not live yet.

The agent wallet

$ONYRA · not launched

A token for compute, priority, and a say.

$ONYRA is designed to pay for cloud credits, to stake for priority on the queue, and to vote when governance opens. None of that is active. The contract address is not live.
