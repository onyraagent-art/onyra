Docs

Read this before you wait.

A short account of how Onyra is meant to work, written while the installers are still being prepared. If a sentence here and a button somewhere else disagree, believe the sentence that says you cannot install it yet.

Pre-release There is no download on this page. Follow @onyraai for the public note when a build exists.

01 — Quick start

The path, once a build exists.

  1. 1

    Install, when you can

    Builds for macOS, Windows, and Linux are not published. When they are, they will be linked from the install section on this page. There is no archive to fetch in the meantime.

  2. 2

    Write a brief

    Say the outcome in plain language. The agent is meant to turn that into a plan on disk before it edits anything.

  3. 3

    Choose the room

    Your computer, for work that should stay on the machine in front of you. Onyra Cloud, for work that should continue after the lid closes, and for a web app that needs a live link.

  4. 4

    Set the ceiling first

    Before auto mode can pay for anything, you set a spending ceiling and the rule for what happens at the line. The wallet is not live, so this step cannot be done yet. It is written here so it is not an afterthought later.

  5. 5

    Read the link and the receipt

    A finished web task is meant to end with a live link and, when money moved, a receipt you can match to the task. Both are part of the result, not a courtesy email.

02 — Words

The few terms worth keeping straight.

Brief
The outcome you asked for, in your words. The agent writes a plan from it. The plan is a file.
Live link
A public URL for a web app the agent produced, hosted so your laptop is not the server. Example addresses on this site are not live.
Safety judge
A check that runs before auto mode takes a sensitive step: spending, deleting, or publishing. It can refuse the plan.
Ceiling
The most the agent wallet may spend. Under it, a task may settle. Over it, the agent waits.
Onyra Cloud
The agent's own machines. Tasks there are meant to continue when your computer sleeps. Not open yet.
Agent wallet
A wallet in the agent's name, funded by you, separate from your personal wallet. Not live.
$ONYRA
The planned token for cloud credits, priority, and governance. Not launched. The contract address is not published.
Helper
Another agent given a slice of a brief. It returns work. It does not get a quieter set of rules.

03 — Questions

Straight answers.

Can I install Onyra today?

No. Onyra is pre-release. Installers for macOS, Windows, and Linux are not published, and this site does not hide a download behind another name. When a build is real, it will be linked from the install section.

What is Onyra for?

You leave a brief. Onyra is being built to do the work: edit files, run commands, use a browser, and publish a web app at a live link. It can do that on your computer, or in Onyra Cloud, which is meant to keep running after you close the lid. When a task needs a paid API, the agent pays from its own wallet, inside limits you set.

What is a live link?

A public URL for a web app the agent has produced, hosted so the page stays up without your laptop acting as the server. The exact shape of those URLs will be documented when Onyra Cloud opens. Addresses in the homepage demonstration are examples.

What happens when the laptop closes?

Work on the local machine pauses when the machine sleeps. Onyra Cloud is the other desk: tasks there are meant to continue, and services the agent starts there are meant to stay available. Cloud is not open yet.

How will spending work?

The agent has a wallet of its own, separate from yours. You fund it on purpose. You set a ceiling, and a rule for anything that would cross it. Payments are per use — the calls and compute that task consumed — and are designed to leave an on-chain receipt. None of this is live. The wallet page is the longer version.

Can it spend without approval?

Not past the rules you set. Under the ceiling, auto mode may settle a cost the task already incurred. Over the ceiling, it waits. The safety judge is there to stop a plan that spends, deletes, or publishes outside those rules. You should still read the receipt.

What is the safety judge?

A check that runs before auto mode takes a sensitive step. It reads the plan and can refuse it. It is not a promise that nothing can go wrong. It is a gate, so “keep going” is not treated as permission to ignore the limits you wrote down.

Where does memory live?

On disk. Plans, notes, and preferences are files you can open, not a transcript trapped in a chat window. You can read them, move them, and delete them.

What is $ONYRA for?

Three uses are planned: paying for Onyra Cloud credits and compute, staking for priority on the queue, and governance over treasury and parameters. None of these are active. The contract has not launched. The token page labels the allocation as a draft.

Where is the contract address?

It is not live. Every page shows “CA: coming soon”. When an address exists, it will be entered once, in js/config.js, and the site will show that same address everywhere. Do not trust an address sent from anywhere else.

Is this an offer to buy the token?

No. The token page is a draft of how $ONYRA is intended to work, including placeholder percentages. It is not an offer, a solicitation, or a promise of profit or supply.

How will I know when I can install it?

Follow @onyraai on X. That is the public channel for this pre-release. There is no mailing list and no download button on this site.

04 — Install

Three systems. None of them yet.

The installers will cover the local agent: files, commands, the browser, memory on disk, and the safety judge. Cloud, the wallet, and the token are later, and they are not bundled in as if they were already open.
