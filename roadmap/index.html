Roadmap

The order of the night.

A plan, not a changelog of a product you can already run. Dates are not promised, and the order can change. The only thing from this list that exists in public today is the letter you are reading.

Phases

  1. Now01

    The night letter

    Publish the product in public: what Onyra is, how the cloud and the wallet are meant to work, and a draft of $ONYRA. This website is that letter. Installers are not part of this phase.

  2. Next02

    The local desk

    An agent on your computer. It can edit files, run commands, use a browser, and keep memory on disk. Auto mode waits on a safety judge. This is the first build a person could install, and it does not exist yet.

  3. Later03

    Onyra Cloud

    Tasks that continue when the laptop is closed. Services that stay up. A live link for each web app the agent ships. No availability claim will be made before the room has actually been open.

  4. Later04

    The agent wallet

    A wallet in the agent's name. Per-use payment for APIs and compute. Spending limits, approvals, and on-chain receipts. The ceiling ships with the wallet, not after it.

  5. Later05

    $ONYRA

    The contract, published with a real address on this site. Utility: cloud credits, staking for priority, and governance — only after the address is real, and only as the published mechanism describes. The draft table is not this phase.

  6. Later06

    Many hands

    Helper agents. Telegram, Discord, and Slack. MCP servers, plugins, and skills. The same ceiling and the same judge, with more doors.

Phases are a sequence we intend to build. They are not dates, and they are not a promise that each one ships in this form.
